# 时效结算台 · 城市末端配送

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

把订单点页面升级为月底时效结算台：每单记录订单金额、承诺/实际送达时间与延迟原因，迟到按规则核算扣款，定责确认后入账，申诉冻结，改判留版本。

## 扣款规则（`src/domain/rules.ts`）

- 普通单：每迟到 5 分钟扣订单金额 2%，单笔封顶 10 元
- 冷链单：迟到超过 30 分钟后，每 5 分钟扣订单金额 4%，单笔封顶 50 元
- 不足一个计费粒度按一个计；客户 / 不可抗力责任免责不扣款

## 结算流程

迟到订单 → 提交定责（待确认）→ 确认扣款；任一环节可申诉（金额冻结），申诉可维持原判或改判；改判生成新版本，旧决定作废留档、随时可查。

## 分层结构

- `src/domain/` — 类型与扣款规则（纯函数，唯一事实来源）
- `src/archive/` — 留档持久化（localStorage，含判定版本历史，重开可按订单核对）
- `src/stores/` — 结算状态机（定责 / 确认 / 申诉 / 改判）
- `src/components/` — 页面（结算看板、判定时间线、按订单核对与月度汇总）
